# Chuck Black — Official Website

Static website for **ChuckBlackMusic.com**. Designed for free GitHub Pages hosting.

## Publish to GitHub

1. Download and extract the ZIP.
2. Open your repository `THAPRODUCT757/chuckblackmusic-website`.
3. Select **Add file → Upload files**.
4. Upload **all files and the `assets` folder contents**, preserving their folder paths. You can drag the extracted files and folder into the upload area. Do **not** upload only the ZIP file.
5. Commit the changes to `main`. In **Settings → Pages**, keep `Deploy from a branch`, `main`, `/ (root)`.
6. Preview at https://thaproduct757.github.io/chuckblackmusic-website/ .
7. Do not change Namecheap DNS or configure the custom domain until you approve the preview.

## Current content status

- Homepage, 12 music entries and release detail pages, videos, about, shows, 757Soundcheck, press and contact are implemented.
- The approved PDF EPK is included in `assets/`.
- Original portrait is preserved visually; cinematic hero uses the previously generated promotional portrait.
- Only the verified NOW LISTEN streaming URL is linked. Artwork, additional official platform URLs, video IDs, tracklists, dates and article links need confirmation.
- Contact form opens the visitor's email application; it is not a hosted form service and does not send messages automatically.
- All links use relative local paths so they work on GitHub Pages under the repository URL.
- No analytics, trackers, or user data collection is included.

## Editing

- `index.html`: homepage.
- `style.css`: appearance and mobile layout.
- `assets/`: images and EPK.
